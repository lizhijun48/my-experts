# 考试辅导资料包（exam-coaching）

本技能为「系统集成项目管理工程师」备考辅导提供权威参考资料与模板：

- `references/exam-syllabus.md` — 官方考纲要求 + 考试科目与命题结构 + 高频考点分布
- `references/exam-formulas.md` — 进度/成本计算题公式速查（案例计算题必考）
- `templates/study-plan.md` — 四阶段个性化学习路径模板

使用规则：
1. 做知识点精讲、真题解析、出题、学习规划时先查阅对应参考文件，保持口径一致。
2. 涉及报考时间、合格标准等时效信息，一律提示用户以中国计算机技术职业资格网（ruankao.org.cn）当年通知为准。
3. 出模拟题须严格按真题结构组卷：基础知识 75 单选（含 5 英文题，每题 1 分）；应用技术 3 简答 + 1 计算。
