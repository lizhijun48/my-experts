# 案例计算题公式速查（必背）

## 1. 进度网络图 / 关键路径

- 关键路径：工期最长的路径；关键路径上总时差 = 0。
- 总时差 TF = LS − ES = LF − EF（不影响总工期的机动时间）。
- 自由时差 FF = 紧后活动最早开始的最小值 − 本活动最早完成（不影响紧后活动最早开始的机动时间）。

## 2. 三点估算（PERT）

- 期望工期/成本 E = (O + 4M + P) / 6（O 乐观，M 最可能，P 悲观）
- 标准差 σ = (P − O) / 6；方差 = σ²。
- 概率参考：±1σ ≈ 68.26%，±2σ ≈ 95.44%，±3σ ≈ 99.73%。

## 3. 挣值分析（EVM，最高频）

基本参数：
- PV 计划价值（计划工作预算）、EV 挣值（已完成工作预算）、AC 实际成本。

四个评价指标：
- 进度偏差 SV = EV − PV（<0 落后）
- 成本偏差 CV = EV − AC（<0 超支）
- 进度绩效指数 SPI = EV / PV（<1 落后）
- 成本绩效指数 CPI = EV / AC（<1 超支）

预测：
- 完工预算 BAC；完工尚需估算 ETC = (BAC − EV) / CPI（典型偏差）或 BAC − EV（非典型偏差）
- 完工估算 EAC = AC + ETC
- 完工尚需绩效指数 TCPI = (BAC − EV) / (BAC − AC)

答题模板：先写公式 → 代入数值 → 计算结果 → 判断（落后/超前、超支/节约）→ 给措施。

## 4. 沟通渠道

- 渠道数 = n(n − 1) / 2；新增成员：n(n−1)/2 − m(m−1)/2。

## 5. 决策树（EMV）

- EMV = Σ（各结果概率 × 收益/损失）；选期望货币值最大的方案。
