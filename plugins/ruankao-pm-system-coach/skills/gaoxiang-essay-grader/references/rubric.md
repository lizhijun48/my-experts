# 高项论文评分细则（agent 定性评判参考）

满分 75，合格 45。权重折算：切合题意 23 / 应用深度 15 / 实践性 15 / 表达能力 11 / 综合能力 11。
以下为各档位判据，agent 据考生论文对号入座打分。

## 1. 切合题意（满分 23）
- **21–23**：论题抓得准，所有子题目要求（通常 2–3 个）逐一回应，论据始终贴题。
- **16–20**：主体切题，个别子题目回应偏弱或一笔带过。
- **≤15**：偏题、漏答任一子题目、或把论文写成教程/复习笔记。
- 硬伤：子题目漏答 → 直接扣到 15 以下。

## 2. 应用深度与水平（满分 15）
- **13–15**：能自然调用绩效域/十大知识领域概念，且每个概念都落回本项目实例。
- **10–12**：概念用对但偏表面，部分堆术语无承接。
- **≤9**：纯理论罗列，或概念误用（如把"敏捷"当万能解）。

## 3. 实践性（满分 15）
- **13–15**：项目背景具体（行业、规模、金额、周期、你的角色、团队人数），有真实数据与踩坑。
- **10–12**：背景清晰但细节偏少，少量"应该怎么做"替代了"我们怎么做"。
- **≤9**：项目像编造（无角色/无数字/泛泛而谈），或全篇正确废话。

## 4. 表达能力（满分 11）
- **10–11**：摘要+背景+正文+结尾结构完整，段落逻辑顺，几乎无语病。
- **8–9**：结构基本完整，偶有病句或衔接生硬。
- **≤7**：结构混乱、大段无分段、错别字多。

## 5. 综合能力与分析（满分 11）
- **10–11**：有方法论层面的总结、对绩效域取舍的反思、风险/变更的独到处理。
- **8–9**：有结尾总结但较套路（"通过本项目我认识到…"无新意）。
- **≤7**：无总结或总结与正文脱节。

## 8 大绩效域关键词（供 score_essay.py 命中检测）
1. 利益相关者：利益相关者 / 干系人 / stakeholder
2. 团队：团队 / 成员 / 协作
3. 开发方法和生命周期：开发方法 / 生命周期 / 敏捷 / 瀑布 / 迭代
4. 规划：规划 / 计划 / WBS / 范围 / 进度
5. 项目工作：项目工作 / 执行 / 监控 / 变更
6. 交付：交付 / 成果 / 验收 / 价值
7. 度量：度量 / 度量指标 / KPI / 评估
8. 不确定性：不确定性 / 风险 / 应对 / 突发 / 未知

## 常见扣分项速查
- 字数 < 2000 → 实践性/表达能力双输。
- 无摘要 → 切题印象分差。
- 子题目漏答 → 切合题意重扣。
- 全篇"我们严格按照 PMBOK 执行"无实例 → 应用深度低。
- 结尾模板化 → 综合能力低。
- 把论文写成"XX 管理教程" → 判不切题。
