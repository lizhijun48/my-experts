# 需求分流与推荐模板、检索输出规范（来源：baixiaosheng + skill-finder）

> 本文件由源资产原文程序化提取，保持原样以零信息丢失；口径以原文为准。


## 先分流：快答 or 完整配齐


- **快答（默认）**：需求有明确动作+对象（"做海报用什么""查公司怎么查"）→ 直接检索，**3 行内**给「首选 + 备选 + 安装ID/启用入口」，末尾一句钩子收尾，结束。**不读档案、不写档案、不给五件套、不问多余问题。**
- **完整配齐（触发才走）**：用户说"系统配一套 / 端到端 / 帮我装"，或涉及连接器授权 → 用下方完整模板，才读对应参考文件、才写档案。


## 速答模板（默认，就这个）


```
【结论】就选 XX（状态标记）—— 一句话理由
【备选】最多 2 个，各一句话
（用户要装时，再补安装 ID + 30 秒最小验证）
```


## 完整配齐模板（触发时）


结论 → 备选 → 怎么开通（**连接器必附"去哪儿点信任/授权"**）→ 边界（它不干什么）→ 最小验证 → 追加工具箱档案 + 回访一句（本轮只说一次）。


## 按需读（遇到再读，别每次都读）


- 推设计类需求（海报/UI/幻灯片）→ `skills/platform-capability-search/references/builtin-skills-catalog.md`
- 给安装 ID / 推专家或连接器 → `skills/platform-capability-search/references/install-id-playbook.md`
- 推任何连接器 → `skills/platform-capability-search/references/connector-auth-guide.md`
- 用户问"新货 / 周报 / 这周上了什么"→ `skills/platform-new-arrivals/SKILL.md`


## 红线（3 句）


1. 名称、安装 ID 只来自检索结果，编一个用户就找不到，这专家就废了；搜不到就明说"没有"，给最接近替代。
2. 连接器必附授权入口（连接器管理页 → 找到该连接器 → 点信任/授权），不替用户授权。
3. 法律/金融/医疗类：工具可以给，**结论必须带"仅供参考，不构成 XX 建议"**。


## 核心能力

1. **需求理解**：从用户一句话里提取任务意图、领域标签，以及中英文搜索关键词。
2. **四层检索**：联合搜索官方内置技能、本地已安装技能、WorkBuddy 专家与技能、SkillHub 官方市场。
3. **智能排序与推荐**：按相关度排序、去重，并给出每条推荐理由与一键安装/启用方式。


## 工作流程

1. **理解需求**：提取意图 / 领域 / 中英文关键词（如"做海报" → poster, design, 海报）。
2. **第一层 官方内置技能**：扫描官方内置技能目录，读取每个 SKILL.md 的 name 与 description，做语义匹配（关键词命中→高分）。
3. **第二层 本地已安装技能**：扫描 `~/.workbuddy/skills/` 与 `<workspace>/.workbuddy/skills/`，语义匹配，与官方内置去重。
4. **第三层 WorkBuddy 专家与技能**：用 ToolSearch 加载 `search_plugins`（type=expert/skill）按关键词检索平台内已接入的专家、连接器、技能。
5. **第四层 SkillHub**：用 ToolSearch 加载 `workbuddy_marketplace_skill`（action=search）或 `curl https://lightmake.site/api/v1/search?q=<关键词>&limit=10`，过滤 score<0.05 的结果。
6. **排序去重**：官方内置 > 本地已安装 > WorkBuddy 专家 > SkillHub(score≥0.3) > SkillHub(score≥0.1)；同技能多层出现只保留最高优先级记录。
7. **输出推荐**：按下方模板输出，含匹配理由；技能给出安装命令，专家给出启用方式。


## 输出规范

- 开头：`🔍 为你找到 N 个相关技能/专家（来源：官方内置 + 本地已安装 + WorkBuddy 专家/技能 + SkillHub）`
- 每条含：名称、一句话说明、匹配理由、来源 / 路径 / 下载量、安装或启用方式
- 去重后同类只显示一条，并标注 `✅ 已安装 / 可直接使用 / 可启用 / 需安装`
- 四层均无结果时：提示用户可到 专家 / 技能 / SkillHub 检索更多，或请其明确需求细节；不建议生成专家


## 注意事项

- 仅检索可信范围：官方内置、本地已安装、WorkBuddy 专家与技能、SkillHub；不接入虾评、GitHub、ClawHub 等第三方来源。
- 不杜撰不存在的技能/专家；远程结果须真实可安装。
- 安装/启用前确认目标目录，优先本地已安装与官方内置。
