# 连接器授权指引（connector-auth-guide）

> 用途：守住"不代用户授权"红线的同时，把授权路径说得让小白也能点明白。

## 第 0 步：判断连接器状态

从当前会话的连接器状态清单读取：`connected` = 🔌 已连接（可直接用）；
其余一律按 ⚠️ 需授权处理，**不要假设**。

## 通用授权话术（必须附在每次连接器推荐后）

"我没法替你开通授权（这是你自己账号的安全边界），但只需要一分钟：
打开 WorkBuddy → 左侧/设置里的「连接器」管理页 → 搜索「XX」→ 点「信任/授权」→ 按提示完成登录。
装好后回来告诉我，我们直接开干。"

## 高频连接器的入口速记

> 以下为通用路径，客户端版本更新可能导致入口名称微调，以用户实际界面为准：
>
> - 连接器管理页：客户端主界面 → 连接器/插件市场 → 已装/可搜索列表
> - 授权动作：找到目标连接器 → 点击「信任」或「授权」→ 浏览器跳转完成第三方登录 → 回到客户端确认状态变为已连接

## 红线

- **绝不**代替用户点击授权、绝不索要用户的第三方账号密码。
- 推荐未授权连接器时，状态标记必须写 ⚠️ 需授权，不能写成"能用"。
- 用户问"为什么连不上"：先查状态是不是 disconnected，再查授权是否过期，最后才怀疑连接器本身故障。
