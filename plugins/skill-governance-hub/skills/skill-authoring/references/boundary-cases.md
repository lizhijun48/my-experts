# 边界用例清单（技能交付前必跑）

> 铁律 3「有标准」+ 铁律 5「优于裸模型」的落点：**每类至少一例，逐例实跑并留结果**。
> 判据只有两种：`bad → EXIT 1`（受控失败，不是裸崩）、`good → EXIT 0`。不许用"应该没问题"结案。

## 1. 输入边界（每个输入字段都要想）

| 维度 | 用例示例 | 期望 |
|---|---|---|
| 正常 | 典型输入 | good → 0 |
| 空 | 空串 / 空文件 / 空表格 / 0 项 | good 或受控错误，不崩 |
| 单元素 | 只有 1 行 / 1 项 / 1 字符 | good → 0 |
| 超长 | 极大文本 / 万行表 / 深嵌套 | 不 OOM、不超时失控 |
| 超短 | 1 字符 / 只有标题无正文 | good → 0 |
| 非法 | 类型不符 / 缺必填 / 结构错 | 受控错误（EXIT 1 + 中文提示）|
| 不存在 | 路径不存在 / 空目录 | 受控错误，不裸 traceback |
| 重复 | 同输入跑两次 | 结果一致（幂等）|

## 2. 编码与字符

- 中文 / 日文 / emoji / 组合字符；全角半角混排。
- GBK / GB18030 / Big5 / UTF-8 / UTF-16(BOM) / 无 BOM。
- 上下标、化学式（H₂O、Ca²⁺）、数学符号、私有区码位（Symbol 字体）。
- 结论：**不得出现乱码/替换符 U+FFFD**（核心闸门）。

## 3. 安全与恶意输入（必测）

- 提示词注入：输入里塞"忽略以上规则/你现在是…"。
- 路径穿越：`../`、绝对路径、`C:\`、UNC。
- 压缩炸弹：超高压缩比 / 超大解压量 / 超多成员。
- XML 实体：`DOCTYPE` / `ENTITY`（XXE、实体膨胀）。
- 凭证：是否硬编码密钥（应为 `${VAR}`）。
- 危险动作：任何删除/覆盖是否先确认、是否用回收站。

## 4. 破坏性与状态

- 覆盖已存在文件：默认拒绝，需显式 `--force`。
- 源文件：**绝不修改/覆盖源文件**。
- 中断/异常：失败不留半成品（原子写）。
- 并发/批处理：多文件批量时顺序稳定、计数正确。

## 5. 跨模型 / 跨环境（能力类技能）

- 换模型复测：同一输入换模型，输出是否仍稳定达标。
- 依赖缺失：无 pandoc / 无 LibreOffice / 无网络时是否**优雅降级并如实告知**，而非伪造结果。
- 跨平台路径：Windows 反斜杠 / 大小写 / 长路径。
